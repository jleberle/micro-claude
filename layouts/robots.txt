# robots.txt for eberle.blog. Replaces the separate AI-blocking plugin.
#
# THIS FILE MUST LIVE IN layouts/, NOT static/ — do not move it back.
# micro.blog ships its own default robots.txt, and a theme/plugin's static/
# copy does NOT override a platform default: the default keeps winning and this
# content never appears. Only a layouts/robots.txt does, because micro.blog has
# Hugo's robots.txt generation enabled and that template renders it.
#
# static/ still works for paths the platform has no default for — humans.txt,
# .well-known/security.txt, css/, fonts/ are all served from static/ today.
# The rule is "static fills a gap, layouts overrides a default", and it was
# learned the hard way: this file spent its first day in static/ and served
# nothing. A local Hugo test is NOT sufficient evidence here — locally a
# static/robots.txt DOES beat Hugo's generated one, which is the opposite of
# what the platform does.
#
# As a template it is rendered by Hugo, so keep it plain text. Go template
# delimiters are live even inside these comment lines — writing a literal pair
# of double braces here is what broke the build the first time this note was
# added ("missing value for command"), which is a fair demonstration of the
# point. Describe them, don't type them.

# ----------------------------------------------------------------------
# Ordinary crawlers: welcome. Nothing here is disallowed.
# ----------------------------------------------------------------------
User-agent: *
Disallow:

Sitemap: https://eberle.blog/sitemap.xml

# ----------------------------------------------------------------------
# AI crawlers: blocked. Two distinct categories, both blocked here to match
# the intent of the plugin this replaces (which blocked GPTBot AND
# ChatGPT-User, i.e. training and user-initiated fetches alike).
#
#   TRAINING / BULK CORPUS — content used to train models.
#   RETRIEVAL / AI SEARCH — fetched to answer a specific user's question,
#     often with a citation back. Blocking these removes the site from AI
#     search results; unblock any you would rather be cited in.
# ----------------------------------------------------------------------
